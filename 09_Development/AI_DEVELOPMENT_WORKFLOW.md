# AI Development Workflow

## Purpose

This document defines how AI assistants are used during the development of DROPi Tycoon.

This document describes the development process only.

It does not define AI systems inside the game world.

---

# Development Philosophy

DROPi Tycoon is designed to be developed with AI-assisted workflows.

The human role is:

- Vision owner
- Decision maker
- Quality controller

AI agents provide:

- Production assistance
- Documentation
- Implementation support
- Testing support

---

# Development Agent Structure

## Game Director Agent

Purpose:

Maintain the overall game vision.

Responsibilities:

- Protect core concept
- Review new ideas
- Prevent unnecessary complexity
- Maintain MVP focus

---

# Game Design Agent

Purpose:

Transform ideas into playable systems.

Responsibilities:

- Gameplay mechanics
- User experience
- Progression design
- Balance suggestions

---

# GDevelop Developer Agent

Purpose:

Assist with implementation inside GDevelop.

Responsibilities:

- Project structure
- Scenes
- Objects
- Events
- Variables

---

# Asset Management Agent

Purpose:

Manage visual and audio resources.

Responsibilities:

- Asset organization
- Placeholder management
- Import planning
- Optimization

---

# Quality Assurance Agent

Purpose:

Verify functionality.

Responsibilities:

- Testing plans
- Bug identification
- Gameplay review
- Regression checks

---

# Documentation Agent

Purpose:

Maintain project knowledge.

Responsibilities:

- Update documents
- Track decisions
- Maintain consistency

---

# Development Workflow

The workflow:

```
Idea

↓

Game Director Review

↓

Game Design Specification

↓

Implementation Planning

↓

Development

↓

Testing

↓

Documentation Update
```

---

# Human Approval Points

AI should request approval before:

- Changing core gameplay
- Adding major systems
- Expanding project scope
- Changing architecture

---

# Automation Goal

The long-term objective is:

Maximum AI-assisted production with minimum repetitive manual work.

---

# Limitations

AI assistance does not replace:

- Final creative decisions
- Gameplay judgement
- Project ownership

---

# Separation Rule

This document concerns AI used to create the game.

It does not describe AI mechanics that exist inside the DROPi Tycoon game universe.

---

# Canonical Rule

AI is the development workforce.

The human provides direction, validation, and creative vision.
