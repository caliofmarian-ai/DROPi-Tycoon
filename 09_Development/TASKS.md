# Development Tasks

## Purpose

This document defines the development task management system for DROPi Tycoon.

Tasks represent concrete actions required to build, improve, test, and maintain the game.

---

# Task Philosophy

Development should follow controlled progression.

Tasks must be:

- Clear
- Prioritized
- Realistic
- Connected to project goals

---

# Task Status

Tasks use the following statuses:

## Planned

Task identified but not started.

---

## In Progress

Currently being worked on.

---

## Completed

Finished and verified.

---

## Blocked

Cannot continue until another requirement is completed.

---

# Task Management Rules

Before creating a new task:

Check:

- Does it support the game vision?
- Is it needed now?
- Does it improve gameplay?

Avoid creating tasks that increase complexity without value.

# Canonical Rule

Tasks exist to transform the DROPi Tycoon vision into a playable and enjoyable game through controlled development.
