# Findings

## HQ defect root cause

The management scene correctly woke `HQInterior`, but the wake handler immediately restarted the scene with no initialization data. `BaseInteriorScene.create()` then set `position` to `location.spawn`, which is the HQ entrance. Therefore the observed Android behavior was deterministic and directly explained by current source.

## Old Company surface

The global gameplay Company button had already been removed by PR #347, but the physical Operations terminal still displayed old abstract company-management terminology. The internal scene remains useful as an implementation component, but the player-facing concept now belongs to physical Operations & Dispatch.

## Canonical integration boundary

The new owner direction is compatible with the existing game-first vision when staged. It would become contradictory only if future token/real-money participation were required for normal progression, if a single physical server were canonized as exactly one country, if world infrastructure enabled permanent griefing/lockout, or if Tycoon inventions were represented as real DROPi features.

## Equity/member-exit interpretation

The owner's rule that departing members can lose unsold company investment was normalized into a coherent distinction:

- member-restricted/internal shares can return to the company treasury/internal pool if the player exits without an eligible transfer;
- external portfolio holdings are separate and are not silently confiscated because the player changes operational membership.

This preserves the intended strategic cost of company migration without making all cross-company investing self-contradictory.

## Founder artifact interpretation

The Company Heart / Founder Artifact is canonized as a high-value in-game historical collectible with temporary morale/brand/economic effects and a recovery path. It cannot erase the company's database identity and is explicitly not an NFT/blockchain requirement.
