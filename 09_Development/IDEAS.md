# Ideas System

## Purpose

This document stores future ideas and possible expansions for DROPi Tycoon.

Ideas are collected here to preserve creativity while protecting the main development direction.

An idea is not a confirmed feature.

---

# Idea Philosophy

New ideas must be evaluated before implementation.

Each idea should answer:

- Does it improve gameplay?
- Does it support the game vision?
- Is it worth the additional complexity?
- Is it suitable for the current development stage?
