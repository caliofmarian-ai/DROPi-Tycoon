# User Interface System

## Purpose

This document defines the User Interface (UI) system of DROPi Tycoon.

The UI provides the player with the information and controls required to manage the company, understand the simulation, and make strategic decisions.

---

# UI Philosophy

The interface should support management gameplay.

The player should always understand:

- Current company status
- Available actions
- Important events
- Operational problems
- Growth opportunities

The UI should provide information without overwhelming the player.

---

# UI Design Principles

## Clarity

Information must be easy to understand.

Important data should always be visible.

---

## Consistency

Similar actions should use similar interface patterns.

---

## Efficiency

The player should access important decisions quickly.

---

## Progressive Information

The interface should reveal complexity gradually.

New systems appear as the company develops.

---

# Main UI Areas

## Main Dashboard

The central management interface.

Displays:

- Company status
- Revenue
- Expenses
- Active deliveries
- Reputation
- Progress

---

## Map Interface

Provides access to the game world.

Displays:

- Zones
- Buildings
- Customers
- Routes
- Company infrastructure

---

## Logistics Panel

Allows management of delivery operations.

Displays:

- Active orders
- Vehicles
- Employees
- Delivery status

---

## Economy Panel

Displays financial information.

Includes:

- Income
- Costs
- Investments
- Growth

---

## Company Management Panel

Allows player decisions.

Examples:

- Hiring employees
- Purchasing vehicles
- Expanding operations

---

# UI Information Hierarchy

Information is organized by importance.

## Critical Information

Always visible.

Examples:

- Money
- Active problems
- Current objectives

---

## Important Information

Available through main menus.

Examples:

- Detailed reports
- Statistics
- Performance

---

## Advanced Information

Available for experienced players.

Examples:

- Optimization data
- Detailed analytics

---

# Notifications

The UI provides feedback through notifications.

Examples:

- Delivery completed
- New opportunity available
- Vehicle problem
- Weather change

Notifications should inform, not distract.

---

# UI and Game Systems

The UI should communicate with game systems through defined interfaces.

The UI does not contain gameplay logic.

Gameplay systems calculate results.

The UI displays them.

---

# MVP UI Scope

The first playable version includes:

- Main dashboard
- Basic map view
- Delivery information
- Company status
- Simple menus

---

# Future Expansion

Possible future UI systems:

- Advanced analytics
- AI assistant interface
- Drone management center
- Multiple city management
- Enterprise dashboards

---

# Balance Principles

The UI must:

- Support decisions
- Reduce confusion
- Present useful information
- Keep the player focused on strategy

---

# Canonical Rule

The UI exists to make the simulation understandable and enjoyable.

A powerful system is useless if the player cannot understand it.
