# Global World Non-Goals

The global direction does **not** require:

- every real city on Earth;
- every real road/building;
- live official economic statistics;
- live real-world wars/politics;
- all global vehicles simulated every frame;
- one physical server per country;
- deleting old worlds when a new world launches;
- importing mature-world money/assets into a fresh world;
- generating thousands of speculative images before mechanics require them;
- turning DROPi Tycoon into a tactical war simulator;
- forcing every country into exactly nine nodes when geography does not support it.

The goal is a believable, evolving global logistics/economy game with sparse representative geography and deep connected simulation.
