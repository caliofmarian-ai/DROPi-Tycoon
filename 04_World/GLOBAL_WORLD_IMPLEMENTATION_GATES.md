# Global World Implementation Gates

## Gate 1 — Foundation
Pure contracts + canon + tests. No save/runtime mutation.

## Gate 2 — Global Map
All-country geography dataset + renderer + country selection. Owner checkpoint.

## Gate 3 — Country Drill-Down
Representative localities, administrative summaries, external productive nodes.

## Gate 4 — Local Integration
Transition into an existing detailed locality scene while preserving state.

## Gate 5 — Active Economy
Production, inventories, contracts, supply/demand, local price differences.

## Gate 6 — Time/Evolution
Day/night plus slower demographic/industrial/world change.

## Gate 7 — World Instances
Multiple persistent logical worlds with isolated economies.

Each gate requires automated validation. Owner review is required only where the gate materially changes player-visible gameplay.
