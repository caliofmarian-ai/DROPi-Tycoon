# External Economic Nodes

Status: Canonical specialization
Last Updated: 2026-09-08

## Purpose

Some of the most important economic assets in DROPi Tycoon exist outside cities and villages. They must be represented as independent geography/economy nodes rather than being forced inside locality scenes.

## Node families

Examples include:

- steelworks / metallurgical complexes;
- chemical plants;
- fertilizer plants;
- paper/pulp mills;
- refineries;
- mines;
- quarries;
- power plants;
- large farms;
- livestock operations;
- forestry operations;
- food-processing plants;
- construction-material plants;
- industrial warehouses;
- regional distribution centers;
- rail freight terminals;
- industrial ports;
- airport cargo terminals.

## Required state

An external economic node should be able to represent:

- geographic position;
- administrative region;
- ownership/control;
- workforce/specialist requirement;
- input products;
- output products;
- production capacity;
- inventory;
- energy/support requirements;
- transport modes/access;
- contracts;
- current operating state;
- expansion/decline state.

## Delivery-company relationship

Progression can evolve through:

1. occasional delivery jobs;
2. recurring logistics contracts;
3. dedicated routes/warehousing;
4. strategic logistics partnership;
5. eligible investment or acquisition;
6. integrated production + distribution + trade.

## Map behavior

External nodes appear as points/facilities on country or regional layers. They receive detailed scenes only when gameplay value justifies one.

A steelworks or remote farm does not require a full surrounding city to exist.

## Economy behavior

External nodes participate in the same supply/demand economy as local marketplaces and cities.

A node can:

- import production inputs;
- produce inventory;
- sell locally or internationally;
- create contract demand;
- become constrained by shortages;
- expand when profitable and supplied;
- shrink/close under sustained adverse conditions;
- change ownership through governed game systems.

## Canonical rule

**Strategic production follows geography. Productive facilities may exist independently from localities and must create physical logistics demand rather than abstract passive income.**
