# Global World Glossary

- **World Instance** — one persistent evolving global economy/history.
- **Global Layer** — planet-wide country/trade view.
- **Country Layer** — one country's strategic map.
- **Administrative Region** — country-neutral first-order division such as state/province/județ/region.
- **Representative Locality** — one selected real capital/urban/rural settlement used as a playable strategic node.
- **External Economic Node** — productive/logistics facility outside a locality, such as farm, mine, steelworks or industrial terminal.
- **Detailed Local Scene** — high-fidelity streets/buildings/actors gameplay area.
- **Economic Tick** — lower-frequency production/inventory/market update.
- **Slow World Cycle** — demographic/urban/national evolution update.
- **Baseline Seed** — versioned initial state used to start a new World Instance.
- **Legacy World** — older persistent World Instance that continues after newer worlds launch.
- **Production Recipe** — fictionalized transformation of input product groups into output groups over time/capacity.
- **Producer Contract** — recurring logistics obligation between a logistics company and productive node.
