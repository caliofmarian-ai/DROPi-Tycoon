# Global Map Implementation Sequence

Status: Executable planning document
Last Updated: 2026-09-08

## Phase 1 — Foundation
- canonical geography hierarchy;
- country-neutral administrative model;
- representative locality roles;
- external economic nodes;
- world clock;
- world-instance identity;
- tests.

## Phase 2 — Global Geography
- versioned low-resolution world country-boundary dataset;
- all-country catalog;
- country centroids/capital metadata;
- mobile-safe world projection;
- global map scene;
- country selection/hover/tap state.

## Phase 3 — Country Drill-Down
- representative-node selection rules;
- first-order administrative-region summary;
- capital + N/E/S/W urban + NE/SE/SW/NW rural/small nodes when valid;
- country economy/transport overlay;
- external productive-node overlay.

## Phase 4 — Regional Drill-Down
- region map;
- locality and external-node routes;
- national/regional road/rail/air/river/sea connectivity;
- regional market summaries.

## Phase 5 — Detailed Local Integration
- existing playable city becomes one locality node;
- preserve exact game session/company state across map transitions;
- local rural scene architecture path;
- competitor caps: urban max 5, rural normally max 2.

## Phase 6 — GPS/UX Reconciliation
- smartphone Map app uses the same world hierarchy;
- breadcrumb navigation Global > Country > Region > Locality;
- zoom and back behavior preserve context;
- economy, traffic and logistics filters share one visual language.

## Phase 7 — Active Economy
- production recipes/inventory;
- local/regional supply-demand;
- dynamic price pressure;
- occasional producer jobs;
- recurring contracts;
- productive asset acquisition;
- trade destination choice.

## Phase 8 — Time and Evolution
- day/night;
- operating-day/market/season/year cycles;
- migration/tourism;
- specialist movement;
- city/rural growth/decline;
- new settlements;
- national development/currency mechanics when separately activated;
- macro events and recovery.

## Phase 9 — World Instances
- versioned baseline seeds;
- parallel persistent logical worlds;
- new-world launch flow;
- mature/legacy-world retention;
- economy isolation between worlds;
- scalable server/shard ownership.

## Asset policy

Do not generate speculative art. Reuse approved assets first. New assets are created only when a concrete phase has a verified missing runtime visual requirement.
