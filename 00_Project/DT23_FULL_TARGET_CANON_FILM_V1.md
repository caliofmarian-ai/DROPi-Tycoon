## Purpose

This film is a visual target for what DROPi Tycoon should become. It is **not** a claim that the currently deployed runtime already has this exact presentation.

The film follows the canonical visual identity from `08_Assets/WORLD_ASSET_BIBLE.md`:

> Stylized 3D Pre-Rendered Mobile World — premium mobile tycoon art with soft-isometric / elevated 3/4 presentation, clear three-dimensional volume, readable materials, consistent soft lighting, controlled color, strong object recognition and mobile-first legibility.

## Sequence

`start -> Player Phone / job -> city route -> DROPi HQ / Parcel Operations -> Mara pickup -> delivery route -> customer handoff -> result -> end card`

The result frame intentionally uses no fabricated numeric rewards. It communicates only canonical progression concepts:

- Personal Money credited;
- XP progressed;
- Loyalty increased;
- `YOUR WORK LEAVES A MARK.`

## Creative constraints

- must look like a game, not live-action cinema;
- no photoreal human actors;
- no fake Google Play / App Store badges;
- no invented release status;
- no fabricated currencies, prices, XP amounts, levels or player counts;
- no claim that this film is `AUTHENTIC GAMEPLAY`;
- no current-runtime lag is part of the target presentation;
- movement must be smooth and readable;
- Brăila is the locality identity;
- DROPi blue/cyan, green and gold/orange remain controlled identity anchors;
- final public use still requires the applicable DT-13 / DT-14 evidence gates.

## Runtime relationship

The current runtime remains implementation evidence, not the aesthetic ceiling. This target film is intended to give visible specialists an explicit presentation goal. Future runtime work should converge toward the canonical art direction rather than forcing marketing to preserve temporary prototype presentation.
